## 2026-08-24：深度改造立项

**背景**：27 届秋招在即（2026 年 9 月），本项目当时只是"一个月原型"（3 关平台跳跃 + 世界切换），技术深度不足、教程痕迹明显、与作者的只狼复刻项目技术重叠。

**决策**：
1. 对本项目进行深度改造，目标 = 秋招差异化旗舰项目
2. 与只狼项目错位互补：只狼做 3D 战斗/AI/HFSM，本项目做 **2D 确定性物理 + 渲染差异化**
3. 完成度档次 **A**：面试深度优先，不做测试/CI 等重工程层
4. 物理线选**方案 2**：从零重写运动学控制器（Kinematic2D），删除教程死代码
5. 维度系统重构：IgnoreLayerCollision → 射线级 ICollisionFilter
6. 渲染三线：双 Volume 后处理差异化 + URP 2D 光照 + 自写 Renderer Feature 转场；移除 PPv2
7. 关卡 3 关全部重做，围绕新物理与视觉设计
8. 文档体系（本次一并建立）：AGENTS.md + Docs/architecture/（AI 用）+ Docs/tests/（验收用）+ Docs/decisions.md（用户查阅）+ total.md（本文件）

**动机记录**：项目最大的短板不是"简陋"而是"平庸的完整"——什么都有点，没有一个点能打。提升方向 = 选一个大多数应届生做不到的深度点打穿，而不是加关卡数量。
