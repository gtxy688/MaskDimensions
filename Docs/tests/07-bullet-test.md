# 07 子弹系统验收清单（bullet-test）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开含 BulletSpawner 的关卡，进入 Play Mode

## 逐条验证

- [ ] **直线弹道**：默认子弹沿水平方向匀速飞行，颜色与 BulletStatsSO 配置一致
- [ ] **正弦弹道**：配置 SineWave 后子弹按频率/振幅摆动
- [ ] **追踪弹道**：配置 Homing 后子弹转向玩家（角速度符合配置）
- [ ] **配置切换生效**：改 BulletStatsSO 的弹道类型/速度/颜色 → 运行中即时生效（无需改代码）
- [ ] **发射间隔**：扫射间隔与 RoomConfigSO.fireInterval 一致
- [ ] **命中玩家**：子弹碰到玩家 → 玩家死亡 + 子弹回池，无重复判定
- [ ] **生命周期**：子弹存活超过 lifetime 自动回池
- [ ] **多发射点**：spawnPoints 多个时依次发射
- [ ] **房间联动**：进入房间激活扫射，离开房间停止扫射（协程正确启停）

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
