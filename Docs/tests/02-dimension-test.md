# 02 维度系统验收清单（dimension-test）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开 GameScene，进入 Play Mode
- 场景中有表世界物体（showWhenMaskActive=false）与里世界物体（showWhenMaskActive=true）
- 玩家物理已接入 Kinematic2D + DimensionCollisionFilter

## 逐条验证

- [ ] **表世界基线**：初始未戴面具，表世界物体可见可踩，里世界物体不可见
- [ ] **切换进里世界**：按 J 切换后，里世界物体出现可踩，表世界物体消失
- [ ] **切换回表世界**：再按 J 回到表世界，显隐反转正确
- [ ] **碰撞过滤**：里世界的墙在表世界不存在（玩家可以直接穿过其位置）；反之亦然
- [ ] **地面正确性**：站在里世界平台上切回表世界 → 玩家坠落（该平台在表世界不存在），落地到表世界地面
- [ ] **显隐无残留**：连续快速切换 5 次，无"物体该显示却没显示/该隐藏却没隐藏"的残留
- [ ] **对象池复用**：子弹/特效回池再取出后，其维度显隐状态正确（复用同步）
- [ ] **预览虚影**：按住 J 进入预览，另一世界物体半透明显示；松开后消失或切换
- [ ] **理智限制**：理智低于 minSanityToSwitch 时无法进入里世界（有提示）
- [ ] **理智耗尽**：里世界理智耗尽强制弹回表世界，无卡死
- [ ] **全局状态已移除**：代码中无 `IsMaskActiveGlobally` 静态字段（AI 自查项，代码审查）
- [ ] **无 IgnoreLayerCollision**：代码中无 `Physics2D.IgnoreLayerCollision` 调用（AI 自查项）

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
