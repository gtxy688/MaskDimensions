# 08 表现层验收清单（presentation-test：UI / 音频 / Tips）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开 BeginScene → 进入 GameScene，完整游玩流程

## 逐条验证（UI）

- [ ] 开始界面：BeginPanel 正常显示，点击进入游戏
- [ ] 游戏面板：理智条/提示正常显示，随理智变化更新
- [ ] 设置面板：音量滑条可调，实时生效
- [ ] 结束面板：通关/死亡后正确显示
- [ ] 面板缓存：重复 ShowPanel 同一面板不重复实例化

## 逐条验证（音频）

- [ ] 菜单 BGM：BeginScene 播放，进 GameScene 停止
- [ ] 双 BGM 切换：进里世界 → 表世界 BGM 暂停、里世界 BGM 播放；回表世界反向切换
- [ ] 音效：死亡/复活/通关 SFX 正常播放
- [ ] 音量持久化：设置音量后退出重进，音量保持
- [ ] 无泄漏：切换多次后音频事件无重复订阅报错（Console 无异常）

## 逐条验证（Tips 提示）

- [ ] 理智不足提示：理智低于门槛尝试切换时出现提示
- [ ] 理智耗尽提示：强制弹回时出现提示
- [ ] 教程 HUD：教学段提示按触发区正确出现/消失
- [ ] Toast：房间名等消息正常弹出与消失

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
