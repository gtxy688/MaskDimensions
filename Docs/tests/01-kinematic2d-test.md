# 01 物理模块验收清单（kinematic2d-test）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开 GameScene（或物理测试场景），进入 Play Mode
- 玩家已接入 KinematicBody（无 Rigidbody2D 组件）
- PlayerConfigSO 数值为默认（moveSpeed 5 / jumpForce 5 / coyote 0.15 / buffer 0.15）

## 逐条验证

- [ ] **基础移动**：左右移动流畅，速度与 moveSpeed 匹配，无抖动/卡顿
- [ ] **跳跃落地**：跳跃高度正常；落地瞬间 IsGrounded 生效，无"悬空半帧"
- [ ] **土狼时间**：走出平台边缘后 0.15s 内按跳仍能起跳；超过 0.15s 后无效
- [ ] **跳缓冲**：落地前 0.15s 内按跳，落地后自动起跳；连按不会二段跳
- [ ] **撞墙**：水平撞墙被正确阻挡，不会嵌入墙体
- [ ] **顶头**：跳跃顶到天花板，垂直速度归零并回落
- [ ] **穿墙回归**：快速斜向移动（对角）不会穿过任何碰撞体
- [ ] **SkinWidth 防卡缝**：贴墙/贴地滑行不会卡进 1px 缝隙
- [ ] **顿帧兼容**：timeScale=0 期间玩家物理冻结（无位移），恢复后正常
- [ ] **无 GC 压力**：移动/跳跃期间 Profiler 无明显每帧分配（GC Alloc 稳定）

## 增量模块（M3 后追加）

- [ ] **斜坡**：爬坡顺畅不抖动；>60° 斜坡按墙处理
- [ ] **下坡**：下坡贴地不腾空
- [ ] **单向板**：从下往上跳穿透；从上往下落踩住；按住下+跳可下穿（如需）
- [ ] **移动平台**：站在平台上随平台移动；跳离后不再跟随

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
