# 04 关卡系统验收清单（levels-test）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开 GameScene（或关卡总场景），从 L1 开始游玩
- 3 关均按设计文档搭建完毕（L1 维度教学 / L2 斜坡动量 / L3 综合压力）

## 逐条验证（关卡功能）

- [ ] **L1 可完整通关**：表/里切换教学段 → 应用段 → 挑战段均可通过
- [ ] **L2 可完整通关**：斜坡冲刺跳、下坡加速跳、单向板上下穿均有关卡场景实际应用
- [ ] **L3 可完整通关**：里世界限时通道（理智压力）+ 连续切换解谜可完成
- [ ] **机制必过检查**：每个机制至少有一处"不用它过不去"（逐条对照设计）
  - [ ] 维度切换：存在表世界无路/里世界有路的关卡点
  - [ ] 斜坡：存在必须靠斜坡冲刺才能跳过的跨度
  - [ ] 单向板：存在必须下穿/上穿的路径
  - [ ] 动量继承：存在切换世界后仍需保持速度才能过的点（如切换后立即长跳）
- [ ] **理智压迫**：L3 中理智耗尽强制弹回有实际惩罚效果（不是摆设）

## 逐条验证（房间框架回归）

- [ ] 进入新房间：相机切换、玩家传送到出生点、理智回满、面具摘除
- [ ] 房间退出：上一房间的 BulletSpawner 停用，新房间激活
- [ ] 死亡重生：回到当前房间出生点，状态完整重置
- [ ] 通关流程：L3 出口 → EndGameTrigger → 结束面板正常
- [ ] 房间参数来自 RoomConfigSO（含扩展字段），改 SO 数值生效无需改代码

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
