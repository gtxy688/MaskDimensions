# 06 对象池验收清单（pool-test）

> 验收方式：用户在 Unity 中手动逐条验证。AI 交付代码时必须附本清单。

## 前置

- Unity 打开含 BulletSpawner 的关卡（L2/L3 弹幕段），进入 Play Mode

## 逐条验证

- [ ] **预热生效**：场景加载后，Hierarchy 中已存在预生成的子弹对象（约 15 个，未激活）
- [ ] **出池复用**：扫射时子弹从池取出，不重复 Instantiate（Hierarchy 数量稳定）
- [ ] **回池**：子弹生命周期结束/命中玩家后回到池（未激活），数量不增长
- [ ] **容量上限**：连续大量发射不超出池容量上限（超出部分被销毁，Hierarchy 数量受控）
- [ ] **防重复入池**：无重复回池报错/队列污染（Console 无 ObjectPool 警告）
- [ ] **状态重置**：子弹出池后位置/速度/颜色正确（无上次残留）
- [ ] **GC 观察**：弹幕持续 30 秒，Profiler 无持续 GC 分配增长

## 通过标准

- 全部勾选 → 验收通过，AI 方可 commit
